# Carousel Images

This folder should contain the carousel/slider images for the home page.

## Required Images

Based on `CarouselConstants.tsx`, you need:

1. **slide1.jpg** - Welcome to Crinfo Global
2. **slide2.jpg** - Academic Journals
3. **slide3.jpg** - Language Services
4. **Note**: slide4 uses `/journals/fei.png` (already exists)

## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 1920x1080 pixels (16:9 aspect ratio)
- **File Size**: Keep under 500KB for optimal loading
- **Quality**: High quality, professional images

## How to Add Images

1. Place your images in this folder (`/public/carousel/`)
2. Name them exactly as specified above
3. Restart the dev server to see changes

## Temporary Solution

Until you add real images, you can:
- Use placeholder images from services like:
  - https://placehold.co/1920x1080
  - https://picsum.photos/1920/1080
- Or copy existing images and rename them
